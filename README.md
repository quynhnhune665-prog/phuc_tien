# PTIEN Math Hunter

**Real problem collection, classification, and workbook generation from verified sources.**

A knowledge acquisition system that discovers, crawls, extracts, deduplicates, and organizes math problems from the internet into structured workbooks.

## Architecture

```
USER REQUEST
     ↓
QUERY BUILDER
     ↓
SEARCH DISCOVERY (Fixture → Bing)
     ↓
URL FILTERING & CRAWLER
     ↓
CONTENT EXTRACTION (HTML/PDF)
     ↓
CANDIDATE CLASSIFICATION
     ↓
4-LAYER DEDUPLICATION
     ├─ Exact Hash
     ├─ Normalized Hash
     ├─ Similarity
     └─ Semantic (Phase 3)
     ↓
REVIEW QUEUE
     ↓
APPROVED PROBLEMS + SOURCES
     ↓
KNOWLEDGE BUILDER (Theory/Formula)
     ↓
WORKBOOK GENERATOR (DOCX)
```

## Core Principle

**No invented problems** — every problem must have a verified source URL.

```
APPROVED problem ⟹ ≥1 valid source URL
```

## Quick Start

### Prerequisites
- Node.js 18+
- Docker & Docker Compose
- PostgreSQL 15+

### Setup

1. **Clone and install**
   ```bash
   git clone https://github.com/quynhnhune665-prog/phuc_tien.git
   cd phuc_tien
   npm install
   ```

2. **Start PostgreSQL**
   ```bash
   npm run docker:up
   ```

3. **Initialize database**
   ```bash
   npm run db:setup
   ```

4. **Seed fixture data (10 problems)**
   ```bash
   npm run db:seed:fixture:10
   ```

5. **Run server**
   ```bash
   npm run dev
   ```

6. **Run E2E test**
   ```bash
   npm run test:e2e:10
   ```

## Database

PostgreSQL schema includes:
- `grades`, `subjects`, `chapters`, `topics`, `subtopics`
- `problems` (with provenance tracking)
- `problem_sources` (≥1 per approved problem)
- `duplicate_groups` & `duplicate_members` (4-layer results)
- `review_queue` (for manual verification)
- `theories`, `formulas`
- `crawl_jobs` (with checkpoint for resume)
- `search_results` (discovery phase)
- `workbooks` (exported DOCX metadata)
